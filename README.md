# VSClicker
By far my favorite HTML/CSS/JS project so far, a clicker game based around Visual Studio Code.
Inspired by Cookie Clicker

# Plot
You are trying to make a game, and you want to add more and more lines to it so that you can upload it to Steam.

# Instructions
Simply click on the VSC logo, then when you have enough lines, use it to get a programming language, which makes more lines for you.
Then, when you have enough lines, you can upload it to steam, winning the game.
